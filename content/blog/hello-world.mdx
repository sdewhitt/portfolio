# Hello World — Welcome to My Blog

Every developer's first post is a "Hello World," so let's lean into the tradition.

## Why start a blog?

I've been meaning to write more for a while. A blog feels like the right format — somewhere to capture ideas before they disappear, share what I'm building, and think out loud about things I'm learning.

Expect posts about:

- **Projects** — deep dives into what I'm building and the decisions behind them
- **Learning notes** — things that clicked for me and might be useful to someone else
- **Career reflections** — thoughts on working in software

## What's this site built with?

This portfolio is built with [Next.js](https://nextjs.org), [Tailwind CSS](https://tailwindcss.com), and TypeScript. The blog itself is powered by **MDX** — Markdown with JSX support — which means I can embed interactive components right inside posts.

That's all for the intro. More posts coming soon.
